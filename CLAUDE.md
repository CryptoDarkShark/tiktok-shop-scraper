# Matchly outreach repo

Before sending any email from this repo, follow `docs/email_rules.md`: HTML with one `<p>` per paragraph plus a
plain-text version with blank lines between paragraphs; greeting and each signature line on their own line; never
one block of text; plain human wording (no bold, bullets or emojis); and one test to info@joinmatchly.com before
any new type of email goes out. Send only via Resend (never Zoho). Never send to brands or creators without the
user's OK on the batch.
